# Map Telegram topics to Codex chats

Use one Telegram topic per Codex chat inside the allowed group, with the project name as a prefix: `Project · Chat title`. Telegram does not support named topics nested inside project topics, so the project/topic/task hierarchy proposed originally cannot provide separate named chat views. A topic per chat gives each conversation its own history, attachments, reporting destination, and display name; explicit attachment to an existing Codex chat is also supported.
