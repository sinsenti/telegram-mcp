# Triage labels

Use these values in the `Status:` line of local tickets when triaging work.

| Role | Status value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Needs maintainer evaluation |
| needs-info | needs-info | Waiting for information |
| ready-for-agent | ready-for-agent | Fully specified and ready for agent implementation |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Wayfinding tickets use their separate `claimed` and `resolved` lifecycle as described in `issue-tracker.md`.
